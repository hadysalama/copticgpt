# Privacy Policy — CopticGPT Plugin

_Last updated: September 18, 2026_

CopticGPT ("the Plugin") is a skills-only plugin for ChatGPT and Codex that provides Coptic Orthodox faith education, Scripture study, liturgical reference, and church ministry materials.

## Data collection

The Plugin **does not collect, store, or transmit any personal data**. It contains no analytics, no tracking, no advertising, and no external network calls. All skill content — instructions and the reference library (Scripture, Agpeya, Synaxarium, Psalmody, liturgies) — is bundled with the plugin and processed locally by the host AI product.

## Conversations

Your conversations with the Plugin are handled by the host platform (ChatGPT or Codex) under that platform's own privacy policy. The Plugin itself receives only the prompt text you send and returns generated text; nothing is retained by the Plugin's publisher.

## Contact

For privacy questions, contact the publisher through the support channel listed in the plugin's directory listing.
