# CopticGPT

A Coptic Orthodox faith companion: Scripture, liturgy, saints, Agpeya, Psalmody, and church ministry materials.

This repository contains the CopticGPT agent skills in two distributable formats:

- **Claude plugin** (`.claude-plugin/`) — installable via the Claude plugin marketplace.
- **OpenAI Codex plugin** (`.codex-plugin/`) — submittable via the OpenAI plugin directory.

## Skills

- `skills/copticgpt/` — the main CopticGPT skill: Coptic Orthodox theology, Scripture, liturgy, Synaxarium, Agpeya, Holy Psalmody, and ministry materials. Includes a text reference library under `skills/copticgpt/references/`.
- `skills/coptic-agent/` — companion agent skill.

Key sources referenced by the skill: suscopts.org, copticchurch.net, tasbeha.org, and copticreader.org (Holy Psalmody and liturgical texts).
